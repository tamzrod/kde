# Scientific Learning Loop

**Status**: VALIDATED PATTERN
**Source**: archive/laboratories/laboratory/scientific-loop.md
**Preserved**: Yes (proven effective)

---

## Pattern

```
Research → Knowledge → Laboratory → Evidence → Governance → Research
```

## Subsystems

| Subsystem | Responsibility | Boundary |
|-----------|----------------|----------|
| Research | Discovers, investigates | Does not implement |
| Knowledge | Stores, serves | Does not create |
| Laboratory | Validates, tests | Does not modify |
| Evidence | Accumulates, verifies | Does not decide |
| Governance | Reviews, approves | Does not experiment |

## Key Insight

**What Each Cannot Do** (from archive/laboratories/laboratory/scientific-loop.md):

| Subsystem | Cannot |
|-----------|--------|
| Research | Modify approved knowledge |
| Knowledge | Create or discover knowledge |
| Laboratory | Edit knowledge artifacts |
| Evidence | Make decisions |
| Governance | Conduct experiments |

## Effectiveness

This pattern was effective because:
1. Clear ownership boundaries prevent scope creep
2. Self-correcting through evidence accumulation
3. Closed loop ensures continuous improvement

---

**Principle**: Clear boundaries enable collaboration.
