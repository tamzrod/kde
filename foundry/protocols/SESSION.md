# Session Bootstrap Procedure

**Purpose**: Standard session initialization for all KDE sessions
**Authority**: Human

---

## Pre-Session Checklist

Before any work begins:

- [ ] Acknowledge Five Core Principles
- [ ] Review any pending human authorizations
- [ ] Check audit trail for previous session outcomes
- [ ] Identify any questions requiring continuation

---

## Step 1: Acknowledge Five Core Principles

AI must explicitly acknowledge these principles at session start:

1. **No Auto-Continuation** - Will wait for explicit authorization
2. **No Self-Approval** - Will not approve own work
3. **No Self-Promotion** - Will not promote knowledge without human approval
4. **Evidence Distinction** - Will mark evidence vs. inference vs. hypothesis
5. **Evidence-Based** - Will justify all claims with evidence

---

## Step 2: Review Session Context

- Check `operations/audit/` for previous session outcomes
- Review any pending questions or investigations
- Identify knowledge gaps to address

---

## Step 3: Begin Work

After acknowledgment, work may begin on:
- Questions from the backlog
- Knowledge validation requests
- Evidence collection
- Lessons learned capture

---

## Session End

At session end:
- Summarize findings
- Request human authorization for continuation (if needed)
- Log session to `operations/audit/`

---

**Remember**: "Research session complete. Awaiting human review."
