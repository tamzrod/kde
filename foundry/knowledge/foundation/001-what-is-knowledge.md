## Working Definition

**Knowledge** is validated understanding that enables effective engineering action.

## Components

| Component | Description |
|-----------|-------------|
| **Validated** | Tested against evidence, survived counterexamples |
| **Understanding** | Internalized beyond raw data - knows why |
| **Enables Action** | Provides basis for engineering decisions |
| **Engineering Context** | Specific to engineering application |

## Distinctions

| Concept | vs. Knowledge |
|---------|----------------|
| Data | Raw facts without context |
| Information | Organized data without action-enablement |
| Belief | Acceptance without validation |
| Opinion | Personal view without evidence requirement |

## Validation Criteria

Knowledge must pass:
1. **Classification Test** - Clearly includes/excludes candidates
2. **Distinction Test** - Distinguishes from related concepts
3. **Methodology Support Test** - Enables validation procedures
4. **Consistency Test** - Coherent with other foundational definitions
5. **Counterexample Test** - Survives edge cases
