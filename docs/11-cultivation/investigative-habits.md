# Investigative Habits

---

## The Simple Idea

Skills require practice. Reading about hypothesis formation doesn't make you good at it. You must practice.

This skill teaches you daily habits that develop and maintain investigative capabilities.

---

## Real-World Observation

Athletes train daily. Even when they have a game in a week, they practice every day. Skills degrade without maintenance.

Investigators should be the same. Daily practice keeps skills sharp.

This is investigative habit formation. It's not about big efforts. It's about small daily practices.

---

## The Daily Investigation Practice

### Morning Question

Start each day with a question:

**Template**:
```markdown
## Today's Question

**Question**: [A question about your work]

**What I expect**: [Your initial hypothesis]

**What I'll look for**: [Where you'll search for evidence]

**By end of day**: [What you want to know]
```

**Example**:
```markdown
## Today's Question

**Question**: Why is the authentication module slower than expected?

**What I expect**: Database query inefficiency

**What I'll look for**: Query logs, performance metrics

**By end of day**: Identify top 3 slow queries
```

### Evidence Logging

Document evidence as you find it:

**Template**:
```markdown
## Evidence Log - [Date]

### Evidence E1
- **Source**: [Where found]
- **Content**: [What it says]
- **Relevance**: [Why it matters]
- **Assessment**: [Strong/Weak]

### Evidence E2
...
```

### Evening Reflection

End each day with reflection:

**Template**:
```markdown
## Evening Reflection - [Date]

### What I Learned
- [Key insight 1]
- [Key insight 2]

### What I Didn't Find
- [Evidence I looked for but didn't find]
- [Implications of absence]

### Tomorrow's Work
- [What to investigate next]
- [Remaining questions]
```

## Weekly Practices

### Question Review

Every Friday, review the week's questions:

| Question | Status | Key Learning |
|----------|--------|--------------|
| Monday's question | Concluded | Root cause identified |
| Tuesday's question | In progress | Evidence gathering |
| Wednesday's question | Concluded | Hypothesis confirmed |

### Pattern Recognition

Look for patterns across investigations:

```markdown
## Pattern Log - Week of [Date]

### Recurring Issues
1. Temperature management appears in 3 of 5 investigations
2. Documentation gaps delay 2 of 3 investigations

### Implications
- Systematic temperature monitoring recommended
- Documentation improvement investigation warranted
```

### Skill Assessment

Evaluate your skills weekly:

| Skill | Rating | Evidence |
|-------|--------|----------|
| Hypothesis formation | Good | Clear hypotheses in 4 of 5 investigations |
| Evidence finding | Needs work | Only found primary sources |
| Source evaluation | Good | Correctly weighted evidence |
| Uncertainty handling | Needs work | Overconfident in 2 conclusions |

## Monthly Practices

### Investigation Audit

Review your completed investigations:

```markdown
## Investigation Audit - [Month]

### Completed
| Investigation | Quality | Key Learning |
|---------------|---------|--------------|
| INV-001 | HIGH | Good hypothesis, thorough evidence |
| INV-002 | MEDIUM | Concluded too early |
| INV-003 | HIGH | Good uncertainty communication |

### Quality Trends
- Improved: Evidence documentation
- Declining: Hypothesis specificity
- Stable: Source evaluation

### Action Items
1. Focus on hypothesis specificity next month
2. Continue evidence documentation improvement
```

## Investigation Hygiene

### Documentation Standards

| Standard | Practice |
|----------|----------|
| **Contemporaneous** | Document as you investigate, not after |
| **Specific** | Use exact quotes, dates, sources |
| **Organized** | Structure from the beginning |
| **Linked** | Connect evidence to hypotheses |

### Version Control for Investigations

Keep track of how conclusions evolve:

```markdown
## Conclusion Evolution

### Initial (Day 1)
"Hypothesis: Vendor component is faulty."

### Revised (Day 3)
"Hypothesis: Vendor component AND installation contributed."

### Final (Day 5)
"Conclusion: Installation error caused failure. Vendor component was not faulty."

### Rationale for Changes
- Day 3: Found evidence of improper installation
- Day 5: Ruled out vendor component through testing
```

## Building Habits

### Start Small

| Instead of... | Try... |
|--------------|--------|
| Daily hour-long practice | 5-minute daily questions |
| Comprehensive evidence logs | Single-sentence evidence notes |
| Detailed weekly reviews | Checkbox at week's end |

### Build Incrementally

**Week 1-2**: Daily questions only
**Week 3-4**: Add evidence logging
**Week 5-6**: Add evening reflection
**Week 7-8**: Add weekly review
**Month 2**: Full practice

### Track Consistency

```markdown
## Habit Tracking - [Month]

| Practice | Target | Actual | Streak |
|----------|--------|--------|--------|
| Daily question | 7/week | 5/week | 2 |
| Evidence log | 7/week | 3/week | 0 |
| Evening reflection | 7/week | 2/week | 0 |

### This Week's Goal
Increase evidence logging to 5 days.
```

## Practice Exercise

**This week, commit to one habit**:

Choose from:
1. **Daily question**: Write one investigation question each morning
2. **Evidence log**: Document at least 3 pieces of evidence daily
3. **Evening reflection**: Spend 5 minutes reflecting on what you learned

**Write your commitment**:

```markdown
## My Investigative Habit Commitment

**Habit chosen**: Daily question

**Practice**:
Each morning, I will write one question about my work:
- What I'm trying to understand
- What I expect to find
- Where I'll search

**Duration**: 2 weeks (until [date])

**Accountability**: Will review with [accountability partner] on [date]

**Starting**: [Tomorrow's date]
```
