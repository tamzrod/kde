# KDE Documentation

**Knowledge Discovery Engine** - An evidence-based research methodology

---

## Welcome

This is the starting point for understanding KDE.

**The Question**: *"What must we understand before we can define Knowledge Discovery Engine?"_

KDE is a research-first initiative. We don't know what KDE will become. This documentation helps us find out.

## Key Principles

| Principle | Description |
|-----------|-------------|
| **No Auto-Continuation** | Explicit human authorization required |
| **No Self-Approval** | Humans approve all work |
| **Evidence-Based** | All claims require evidence |
| **Distinguish Types** | Clear fact/inference/hypothesis |
