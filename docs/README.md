# KDE Documentation

**Knowledge Discovery Engine** - An evidence-based research methodology

---

## Overview

KDE is a systematic research framework that combines scientific rigor with AI-powered investigation capabilities.

### Core Components

| Component | Purpose |
|-----------|---------|
| **Engine** | Reasoning methodology |
| **Seed** | Foundational principles |
| **ECU** | Execution orchestration |
| **Governance** | Rule enforcement |

### Getting Started

1. Start the engine
2. Run pre-flight check
3. Begin investigation
