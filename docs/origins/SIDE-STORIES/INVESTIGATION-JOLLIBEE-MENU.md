# Investigation Report: Jollibee Menu Identifiers

## Investigation Summary

This investigation examines the use of compact menu identifiers (such as C1) at Jollibee restaurants to determine whether these identifiers demonstrate evidence of **context compression**—where a short identifier represents a larger shared understanding.

|---------|---------|--------------|
| Compact identifiers exist | C1 visible on menu board | ✅ Verified |
| C1 = specific meal combo | "2pcs Chickenjoy w/ 1 Side & Drink" | ✅ Verified |
| Identifiers are category-specific | C1 under Chickenjoy category | ✅ Verified |
| Menu uses predefined combos | Multiple combo options listed | ✅ Verified |

### Engineering Interpretation

**Context Compression Hypothesis:**

The C1 identifier demonstrates a form of **context compression**:

1. **Compression:** A 2-character code ("C1") represents a 36-character description ("2pcs Chickenjoy w/ 1 Side & Drink")

2. **Shared Context:** Both the menu system and the customer/crew share the understanding of what C1 means

3. **Cognitive Load Reduction:** During high-volume ordering, saying "C1" is faster and less error-prone than reciting the full description

4. **Operational Efficiency:** The crew can quickly input orders using codes rather than describing each item verbally

**Note on Interpretation:** This analysis is based on observable patterns and general knowledge of fast-food operations. The specific operational rationale for C1 identifiers was not documented in available sources.

### Hypotheses (Not Verified)

The following remain hypotheses without supporting evidence:

- Whether C1 stands for "Chickenjoy #1" or has another meaning
- Whether identifiers vary by country or over time
- Whether crew use different codes than those shown to customers
