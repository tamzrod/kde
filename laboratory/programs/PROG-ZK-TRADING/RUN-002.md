---

## Methodology

### Return Calculation

```
return[t] = (close[t] - close[t-1]) / close[t-1]
```

### Statistical Tests

1. **Normality Test**: Calculate skewness and kurtosis
2. **Autocorrelation**: Measure correlation between returns at different lags
3. **Stationarity**: Test if statistical properties change over time
4. **Variance Clustering**: Measure if high variance periods cluster

### Definitions

| Term | Definition |
|------|------------|
| Random Walk | Each return is independent of previous returns |
| Persistence | Positive autocorrelation (trends persist) |
| Mean Reversion | Negative autocorrelation (revert to mean) |
| Fat Tails | More extreme values than normal distribution |

## Autocorrelation Analysis

| 5 | +0.005 | Negligible |

### Interpretation

**OBS-003**: First-lag autocorrelation is weakly negative (-0.023)

**Evidence**: Slight mean-reversion tendency at 1-minute scale

**OBS-004**: Autocorrelation decays rapidly

**Evidence**: By lag 5, autocorrelation is essentially zero

### Implication

**Cannot reject random walk hypothesis** at 1-minute scale.

### SB-003: Volatility Clustering

### SB-004: Volume-Return Coupling

**Type**: Extreme returns associated with elevated volume

**Evidence**: Large moves (>|0.3|) have 50% higher volume
