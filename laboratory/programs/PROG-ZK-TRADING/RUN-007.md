## Methodology

### Sequence Types

Search for patterns of length 1-5 candles that predict next-period behavior:

1. **Single-Candle Patterns**: Does current state predict next?
2. **Two-Candle Sequences**: Does A→B predict C?
3. **Setup Patterns**: Do specific conditions precede moves?
4. **Continuation Patterns**: Does pattern X predict X again?

### Prediction Targets

| Target | Definition |
|--------|------------|
| Next Return | Return in T+1 |
| Next Direction | Up/Down in T+1 |
| Next Volatility | Volatility in T+1 |
| Next State | State in T+1 |

### Testing Framework

For each sequence:
1. Count occurrences
2. Measure mean target value
3. Compare to baseline
4. Test statistical significance
