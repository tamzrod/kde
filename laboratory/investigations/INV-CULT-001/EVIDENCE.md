# INV-CULT-001 Evidence

## Evidence 1: Documentation Structure Analysis

[Evidence] Current documentation follows this structure:
- 1-Introduction (what, why, vision)
- 2-Foundations (philosophy, engineering, inspirations)
- 3-History (evolution)
- 4-Getting-Started (setup, first run)
- 5-Core-Concepts (engines, seeds, ecu, laboratory, knowledge)
- 6-How-It-Works (processes, evidence)
- 7-Guides (practical tasks)
- 8-Architecture (technical)
- 9-Reference (commands, glossary)

Source: Repository documentation index

## Evidence 2: Philosophy Teaches Principles, Not Practice

[Evidence] The philosophy section lists five principles:
1. No auto-continuation
2. No self-approval
3. No self-promotion
4. Distinguish evidence types
5. Evidence-based changes

[Evidence] The philosophy does not teach how to:
- Recognize when you're violating a principle
- Internalize principles into habits
- Apply principles in ambiguous situations

Source: docs/2-foundations/philosophy.md

## Evidence 3: Evidence Section Defines Types, Not Discovery

[Evidence] Evidence documentation defines three types:
- Evidence (verified fact)
- Inference (conclusion from facts)
- Hypothesis (speculation)

[Evidence] Evidence documentation does not teach:
- How to find evidence when you don't know where to look
- How to search systematically
- How to know when evidence doesn't exist

Source: docs/6-how-it-works/evidence.md

## Evidence 4: Processes Define Loop, Not Application

[Evidence] Scientific loop is defined as:
OBSERVE → HYPOTHESIZE → PREDICT → TEST → ANALYZE → ITERATE?

[Evidence] Each step is defined but not explained:
- Observe: "Gather data"
- Hypothesize: "Form a testable idea"
- Predict: "What should be true if correct"
- Test: "Check the prediction"
- Analyze: "What did the test reveal"
- Iterate?: "Continue or conclude"

[Evidence] No guidance on:
- How to observe effectively
- What makes a good hypothesis
- How to design a test
- How to recognize failure

Source: docs/6-how-it-works/processes.md

## Evidence 5: First Investigation Teaches Template, Not Thinking

[Evidence] First investigation guide provides a template:
- Objective (what you're investigating)
- Scope (what you cover)
- Evidence (what you found)
- Conclusions (what you conclude)
- Next Steps (what happens next)

[Evidence] Template teaches structure but not:
- How to determine what to investigate
- How to scope appropriately
- How much evidence is enough
- When to conclude

Source: docs/4-getting-started/first-investigation.md
