## 4. Lessons Learned

### 4.1 Investigation Naming Pattern

Following the same pattern as Rule 6 (Experiment Identifier Permanence):

| Type | Pattern | Example |
|------|---------|---------|
| Experiments | `LAB-XXX` | LAB-001, LAB-040 |
| Investigations | `INV-XXX` | INV-001, INV-087 |

### 4.2 Internal Structure is Flexible

Inside the `INV-XXX/` folder, any folder/file structure is allowed:

```
INV-001/
├── investigation.md
├── subfolder/
│   └── document.md
└── any-structure/
```
