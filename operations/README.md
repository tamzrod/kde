## Session Rule

Every new session SHALL begin by reading `roadmap/ROADMAP.md` and determining:
1. Where were we?
2. What was completed?
3. What remains?
4. What is today's objective?

## Five Core Principles

All operations MUST follow the Five Core Principles:

1. **No Auto-Continuation** - Wait for human authorization
2. **No Self-Approval** - Only humans approve
3. **No Self-Promotion** - Only humans promote knowledge
4. **Distinguish Evidence** - Mark evidence vs. inference
5. **Evidence-Based** - Justify all claims
