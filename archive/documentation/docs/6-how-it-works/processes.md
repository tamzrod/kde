# Processes

---

## The Simple Idea

KDE has two core processes:

1. **How you investigate** — The scientific loop
2. **How documents evolve** — State transitions

These aren't arbitrary rules. They're how systematic inquiry works.

---

## The Scientific Loop

Every investigation follows this pattern:

```
OBSERVE → HYPOTHESIZE → PREDICT → TEST → ANALYZE → ITERATE?
```

| Step | What It Means |
|------|---------------|
| **Observe** | Gather data, collect facts |
| **Hypothesize** | Form a testable idea |
| **Predict** | What should be true if hypothesis is correct |
| **Test** | Check the prediction |
| **Analyze** | What did the test reveal? |
| **Iterate?** | Continue or conclude? |

This is how science has worked for centuries. KDE applies it to knowledge work.

---

## Investigation Lifecycle

Investigations progress through states:

```
PROPOSED → APPROVED → IN_PROGRESS → REVIEW → COMPLETE
```

| State | Meaning | Required Action |
|-------|---------|-----------------|
| **PROPOSED** | Awaiting authorization | Human decides |
| **APPROVED** | Authorized to proceed | Begin work |
| **IN_PROGRESS** | Active investigation | Conduct inquiry |
| **REVIEW** | Awaiting review | Submit findings |
| **COMPLETE** | Finished | Document closure |

Every transition requires human action. This is intentional.

---

## Document Lifecycle

Documents evolve through states:

```
DRAFT → REVIEW → APPROVED → VALIDATED → PROMOTED
```

| State | Who Acts | Meaning |
|-------|----------|---------|
| **DRAFT** | AI | Work in progress |
| **REVIEW** | Human | Submitted for review |
| **APPROVED** | Human | Reviewed and approved |
| **VALIDATED** | Laboratory | Tested and confirmed |
| **PROMOTED** | Human | Moved to knowledge base |

---

## Bootstrap Gates

Before starting any work, verify:

| Gate | Checks | Purpose |
|------|--------|---------|
| **B1** | Runtime, workspace, rules | Environment ready |
| **B2** | Git log, status | Repository clean |
| **B3** | Python, dependencies | System ready |

These aren't bureaucratic. They're how you know you're ready.

---

## Who Decides What

| Decision | Who Decides | Why |
|----------|-------------|-----|
| Begin investigation | Human | Prevent unauthorized work |
| Approve investigation | Human | Quality control |
| Approve document | Human | Independence |
| Validate work | Laboratory | Systematic check |
| Promote knowledge | Human | Official status |

Humans govern. AI assists.
