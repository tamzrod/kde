## Phase 2: Heise-Style F2L

### Goal
Solve first two layers (F2L) intuitively in ~12 moves.

### The Philosophy

**"Don't memorize. Understand."**

Unlike CFOP F2L with 41 algorithms, Heise F2L relies on spatial reasoning. You push corner-edge pairs into slots using natural movements.

### Core Concepts

#### 1. The Slot

```
Each slot has 4 states:

EMPTY     вҶ’ Piece needs to be inserted
FILLED    вҶ’ Slot is complete
MISPLACED вҶ’ Wrong piece in slot
SOLVED    вҶ’ Slot matches target color
```

#### 2. The Four Moves

```
в”Ңв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”җ
в”Ӯ                                                    в”Ӯ
в”Ӯ   R U R' U'   вҶҗ Bring corner down, edge ready     в”Ӯ
в”Ӯ   R U' R' F   вҶҗ Insert from top-right             в”Ӯ
в”Ӯ   F' U' F     вҶҗ Insert from top-front             в”Ӯ
в”Ӯ   U' R U R'   вҶҗ Rotate corner to bottom           в”Ӯ
в”Ӯ                                                    в”Ӯ
в””в”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”Җв”ҳ
```

#### 3. The Pair Principle

**Always look for connected corner + edge pieces.**

```
Good:  [White-Yellow corner] + [White-Yellow edge] = PAIR
       вҶ“
       Put them together, then insert

Bad:   [White-Yellow corner] + [White-Green edge] = NO PAIR
       вҶ“
       Find the matching pair first
```

### Step-by-Step F2L

```
Step 1: Find any corner on the first layer
         вҶ“
Step 2: Find its matching edge (same colors)
         вҶ“
Step 3: Form the pair (corner on bottom layer, edge anywhere)
         вҶ“
Step 4: Insert pair into its slot
         вҶ“
Step 5: Repeat 3 more times
```

### F2L Decision Tree

```
Is the corner on the bottom layer?
в”Ӯ
в”ңв”Җ YES: Is it in the right position?
в”Ӯ      в”ңв”Җ YES: Is the edge connected?
в”Ӯ      в”Ӯ      в”ңв”Җ YES: Insert (R' F R F')
в”Ӯ      в”Ӯ      в””в”Җ NO: Connect edge, then insert
в”Ӯ      в””в”Җ NO: Move corner to bottom
в”Ӯ
в””в”Җ NO: Is the corner in the top layer?
       в”ңв”Җ YES: Is edge in a slot?
       в”Ӯ      в”ңв”Җ YES: Pop edge out, repeat
       в”Ӯ      в””в”Җ NO: Bring corner down
       в””в”Җ NO: Corner is in bottom layer slot
              в””в”Җ Pop out and restart
```

## Phase 3: COLL (Corner Orientation + Last Layer) — **KDE SYNTHESIS INNOVATION**

### Goal
Solve the last layer corners while preserving edges in ~10 moves.

### Why COLL?

| Comparison | CFOP OLL+PLL | COLL+EPLL | Winner |
|------------|--------------|-----------|--------|
| Algorithms | 57 + 21 = 78 | 57 + 4 = 61 | COLL вң… |
| Move count | ~12 | ~10 | COLL вң… |
| Preserves edges | No | Yes | COLL вң… |

> **KDE SYNTHESIS INSIGHT**: The Law of Diminishing Returns shows that 57 COLL algorithms = 90% of ZBLL's benefit (493 algorithms) at only 12% of the complexity. This is the **sweet spot** discovered through KDE analysis.

### The 57 COLL Algorithms (The KDE Synthesis Sweet Spot)

Don't panic! We learn these in logical groups:

#### Group 1: Sunes (12 algorithms)

```
Pattern: в•і в•і в•і
         в”Җ в”Җ в”Җ
         
         вӯ® вҶ» вӯ®
         
Solution: R U R' U R U2 R'
```

**When**: Corners need to rotate clockwise (вӯ®)
**Key**: Learn the U-shaped patterns

#### Group 2: Anti-Sunes (12 algorithms)

```
Pattern: в”Җ в”Җ в”Җ
         в•і в•і в•ӯ
         
         вӯ® вҶә вӯ®
         
Solution: R U2 R' U' R U' R'
```

**When**: Corners need to rotate counter-clockwise (вӯҜ)
**Key**: Anti-sune = Sune + U'

#### Group 3: H-Symmetries (6 algorithms)

```
Pattern: в”ј в”ј в”ј
         в”ј в”ј в”ј
         
         в•і в•ӯ в•і
         в•і в•ӯ в•і
         
Solution: R2 D' R U2 R' D R U2 R
```

**When**: All corners oriented but edges need swapping
**Key**: H = horizontal line pattern

#### Group 4: Pi-Symmetries (6 algorithms)

```
Pattern: в•ӯ в•ӯ в•ӯ
         в•ӯ в•ӯ в•ӯ
         
         вӯ® вҶ» вӯ®
         
Solution: R U2 R2 U' R2 U' R2 U2 R
```

**When**: Pi-shaped corner pattern
**Key**: Three corners need rotation

#### Group 5: T-Symmetries (4 algorithms)

```
Pattern: в”Җ в”Җ в•ӯ
         в”Җ в”Җ в•ӯ
         
         в•і в•і вӯ®
         в•і в•і вӯ®
         
Solution: R U R' U' R' F R2 U' R' U' R U R' F'
```

**When**: T-shaped corner pattern
**Key**: Two adjacent corners solved

#### Group 6: L-Symmetries (8 algorithms)

```
Pattern: в•ӯ в”Җ в”Җ
         в•ӯ в”Җ в”Җ
         
         вӯ® вҶ» в•і
         вҶ» вӯ® в•і
         
Solution: F' R U R' U' R' F R
```

**When**: L-shaped corner pattern
**Key**: Corner headlights on left

#### Group 7: Headlights (9 algorithms)

```
Pattern: в•ӯ в•ӯ в”Җ
         в•ӯ в•ӯ в”Җ
         
         вӯ® вӯ® в•і
         вӯ® вӯ® в•і
         
Solution: R' F R2 U' R' U R' F' R U R2
```

**When**: Two corners solved (headlights)
**Key**: The solved corners face YOU

## Phase 4: L5E (Last 5 Edges)

### Goal
Solve the remaining 5 edges in 3 moves or fewer.

### When to Use

After COLL, you have:
- вң… All corners solved
- вң… U face is solid color
- вқҢ 5 edges need positioning

### The 5 L5E Algorithms

| Pattern | Name | Algorithm | Moves |
|---------|------|-----------|-------|
| в•җв•җв•җ | Opposite swap | M' U' M U2 M' U' M | 6 |
| в”Җв”Җв”Җ | Three-cycle | M' U' M U' M' U2 M | 6 |
| в”Җв”Җв”Җ | Adjacent swap | M' U M2 U M' U2 M | 6 |
| в•ів”Җв”Җ | Diagonal | M2 U' M2 U M2 U M2 | 6 |
| в”Җв”Җв”Җ | Edge flip | M' U M' U' M' U M' U' | 8 |

### Quick Reference

```
M = Middle slice (move like L + R')
U' = Up counter-clockwise
M' = Middle counter-clockwise

Memory trick: "M, U, M, U" = cycle edges
```

## Troubleshooting

### Problem: F2L takes too long
**Solution**: 
- Stop memorizing. Watch how pieces move.
- Use the 4 core moves until it clicks.
- 80% of F2L improvement comes from intuition, not algorithms.

### Problem: Can't recognize COLL patterns
**Solution**:
- Look at the U-face first (which color is where?)
- Then check edge orientation
- Practice recognition: show cube for 2 sec, name the COLL

### Problem: Too many algorithms to remember
**Solution**:
- You only NEED 20 for 80% of cases
- Learn by solving, not drilling
- Use muscle memory, not conscious thought

### Problem: Slow transition between phases
**Solution**:
- Practice phase transitions specifically
- F2LвҶ’COLL: Look at U-face while doing last F2L pair
- COLLвҶ’L5E: No pause - recognize and execute
